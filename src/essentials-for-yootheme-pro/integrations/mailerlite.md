# MailerLite Integration

<div class="tm-resource-icon">
    <!--@include: ./assets/brands/mailerlite.svg-->
</div>

The MailerLite integration is available through [MailerLite Action](../addons/forms/actions/mailerlite). Use an API key to create, update, delete, or forget subscribers.

::: warning MailerLite Classic Accounts
This integration is built for the **new MailerLite** platform only, for accounts created after March 2022. It does **not** support MailerLite Classic accounts (created before March 2022), which rely on a different, incompatible API.

If you're on a MailerLite Classic account, [migrate to the new MailerLite](https://www.mailerlite.com/mailerlite-vs-mailerlite-classic) or send your form data through the [Webhook Action](../addons/forms/actions/webhook) instead.
:::
